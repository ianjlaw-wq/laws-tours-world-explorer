# Laws Tours — World Explorer

A mobile-first, browser-based 3D exploration adventure. First destination: **Machu Picchu, Peru**.

Built with [Babylon.js](https://www.babylonjs.com/) (Apache-2.0), TypeScript and Vite. Deployed to GitHub Pages.

## Play

- **Touchscreen (landscape):** fixed joystick bottom-left (push further to run), swipe anywhere else to look, pinch to zoom, JUMP button to jump, TALK / EXAMINE / TAKE / WATCH button to interact, 📖 for the Journal.
- **Top-right controls:** **CC** subtitles on/off, **🔊** Killa's spoken voice on/off, **⚙** pause/settings (voice, subtitles, sound, controls). Preferences are saved in the browser.
- **Keyboard & mouse:** WASD / arrow keys to walk, Shift to run, Space to jump, drag to look, mouse wheel to zoom, E to interact, Enter / 1-4 in conversations, J for the Journal, Esc to close panels or skip the introduction / transformation.
- URL options: `?fps` shows frame-time statistics (average, worst frame, counts of frames over 33 / 50 ms, JavaScript vs render time, draw calls); `?quality=low` disables shadows and grass for slower phones.

### Killa's voice

Killa speaks using the browser's built-in **speech synthesis** (Web Speech API). It is free and needs
no account, but the voice is generated by the phone/browser: quality varies by device and it is **not
a recorded actor**. If the browser refuses to start speech automatically, a **▶ Play voice** button
appears; if speech is unavailable or muted, subtitles are shown automatically. Each dialogue line can
take an optional `clip` (audio file URL) in `src/game/story.ts`; recorded lines would then play instead
of synthetic speech.

## Develop

```bash
npm install
npm run dev        # local dev server (http://localhost:5173/laws-tours-world-explorer/)
npm run build      # type-check + production build into dist/
npm run preview    # serve the production build (http://localhost:4173/laws-tours-world-explorer/)
npm run smoke      # headless browser smoke test against the preview server (screenshots in test-output/)
npm run touchtest  # real multi-touch (CDP) checks of the fixed joystick, camera gestures and JUMP
npm run advtest    # end-to-end adventure test: Killa, transformation, coins, puzzle, chamber, journal, saves
npm run dtest      # Milestone D: spoken welcome, cinematic, CC/voice controls, fallbacks, arrow, saves, old saves
npm run perfprobe  # WebGL draw calls per frame at fixed viewpoints (compare builds; not phone timings)
```

The smoke test needs a Chromium binary: it uses the Playwright browser cache, or set `CHROME_PATH`.

## Saving

Progress is saved automatically in the browser's localStorage (key `ltwe.save.v1`) every few seconds,
on every collectible/puzzle/dialogue event and when the page is hidden: last safe position, checkpoint,
collected coin IDs, gold, solved puzzles, discovered landmarks, transformation and dialogue flags.
The loading screen offers *Continue* or *New journey*; the Journal also has a reset button.
Voice/subtitle/sound preferences are stored separately (`ltwe.prefs.v1`) and survive a new journey.
Milestone C saves load safely (e.g. a save that had seen the transformation but not met Killa gets a
short greeting from her at the guardhouse instead of the full opening).

## Accuracy and assets

- **The landscape and ruins are an artistic approximation** inspired by the real layout of Machu Picchu (saddle between Machu Picchu Mountain and Huayna Picchu, Sun Gate on the south-east ridge, agricultural terraces, main plaza, upper/lower sectors). Distances and heights are compressed for gameplay; it is **not** survey-accurate.
- **Photo textures:** CC0 (public domain) from Poly Haven. See `public/textures/LICENSE.md`. Regenerate with `node scripts/prepare-textures.mjs`.
- Geometry, the explorer, foliage cards, clouds and audio are generated in code. Libraries: Babylon.js (Apache-2.0); Vite/TypeScript (build-time only).

- **Story vs history:** Killa, the hidden chamber, the carved doorway, the turning-stone mechanism and the golden llama are fictional.
  The living city (people, roofs, crops, smoke) is an artistic impression; crop placement on the terraces is plausible, not archaeologically established.
  Journal notes and dialogue notes are tagged **History** (documented / widely accepted) or **Story** (invented).
